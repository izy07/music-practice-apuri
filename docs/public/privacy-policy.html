音楽練習支援アプリケーション「Music Practice」

最終更新日: 2026年9月25日

1. 基本方針

本アプリは、お客様の個人情報の保護を最重要事項と考え、個人情報保護法および関連法令を遵守し、適切な個人情報の取得、利用、管理を行います。本プライバシーポリシーは、音楽練習支援アプリケーション「Music Practice」（以下「本アプリ」といいます）における個人情報の取り扱いについて定めるものです。

本アプリは iOS・Android・Web ブラウザ上で提供されます。Web版では、認証状態や設定の保持のためにブラウザの localStorage 等を使用する場合があります。

2. 収集する個人情報の範囲

本アプリは、サービスの提供に必要な範囲内で、以下の個人情報を収集いたします。

アカウント情報: メールアドレス、パスワード（暗号化保存）

プロフィール情報: 表示名、楽器の種類、練習設定、練習レベル、外観設定

練習記録: 練習時間、練習内容、目標設定、達成状況

演奏データ: 録音・録画ファイル、楽曲情報（マイライブラリ等）

カレンダー情報: 練習日程、イベント記録

サブスクリプション情報: プラン種別、購入状態（決済情報自体は App Store / Google Play が管理）

デバイス情報: 端末の種類、OSバージョン、アプリバージョン、プラットフォーム（web / ios / android）

ログ情報: アクセスログ、エラーログ、使用統計

機能利用ログ: 画面表示・主要操作（機能ID、操作種別、プラットフォーム、セッションID、記録日時、選択中の楽器ID）。録音内容、練習内容の詳細、メモの本文は含みません。metadata フィールドには、操作に必要な最小限の情報のみを JSON 形式で記録する場合があります。

3. 個人情報の利用目的

収集した個人情報は、以下の目的で利用いたします。

本アプリの提供・運営

ユーザー認証・セキュリティの確保

練習記録の管理・分析

カスタマイズされた練習メニューの提供

サブスクリプションの提供・管理

お客様サポート・お問い合わせへの対応

サービスの改善・新機能の開発（機能利用ログを用いた利用状況の把握、機能削減の検討、品質改善）

広告配信の最適化（フリープランのみ）

法令に基づく対応

4. アプリの権限と使用目的

【マイク権限】

使用目的: ユーザー自身の演奏を録音するために使用します。

使用タイミング: 録音機能を起動した時のみ、マイクへのアクセスを要求します。

データの取り扱い: 録音された音声データは、ユーザー本人のアカウントにのみ保存され、他のユーザーや第三者と共有されることはありません。

【カメラ権限】

使用目的: ユーザー自身の演奏を録画するため、および楽器の演奏姿勢を確認するために使用します。

使用タイミング: 録画機能または姿勢確認機能を起動した時のみ、カメラへのアクセスを要求します。

データの取り扱い: 録画された動画データは、ユーザー本人のアカウントにのみ保存されます。姿勢確認機能で撮影した画像は、端末に一時的に保存される場合がありますが、クラウドには保存されません。

【ストレージ権限（画像・動画の選択）】

使用目的: プロフィール画像の設定や、既存の録音・録画ファイルを選択するために使用します。

使用タイミング: プロフィール画像を変更する時、または既存のファイルを選択する時のみ、ストレージへのアクセスを要求します。

【通知権限】

使用目的: 練習リマインダーやアプリからのお知らせを送信するために使用します。

使用タイミング: ユーザーが通知設定を有効にした時のみ、通知権限を要求します。

すべての権限は、ユーザーが明示的に許可した場合にのみ使用され、許可されなかった場合でも、該当機能以外のアプリの基本機能は利用できます。

5. 録音・録画データの取扱い

【データの保存場所と方法】

保存場所: クラウドストレージ（Supabase Storage）に保存されます。

アクセス権限: ユーザー本人のみがアクセス可能です。

共有機能: 他のユーザーとの共有機能、SNSへのシェア機能は提供しておりません。すべてのデータは完全にプライベートです。

【ファイルサイズ制限】

音声ファイル: 10MB以下を推奨

動画ファイル: 50MB以下を推奨

【保存期間】

演奏録音: アカウント削除時まで保存

レッスン録音: 30日後に自動削除（お気に入り登録したものを除く）

録画データ: アカウント削除時まで保存

【未成年者の録音・録画データに関する注意事項】

18歳未満の未成年者が録音・録画機能を利用する場合、保護者の方は事前に説明し、同意を得てください。データはクラウドに保存されますが、第三者と共有されることはありません。

【録音・録画データへのアクセス】

当社は、サービスの改善・品質向上、不正利用の検知・防止、法令遵守（裁判所命令、捜査機関からの要請等）の目的に限り、録音・録画データにアクセスすることがあります。

通常の運用において、当社がお客様の録音・録画データの内容を確認することはありません。

6. 広告配信サービスの利用

本アプリのフリープランでは、広告配信のために Google AdMob（提供元: Google LLC）を利用しています。

【広告の種類】

バナー広告（画面上部または下部に表示）

リワード広告（動画視聴で演奏録音の追加記録等の報酬を得る）

【AdMobが収集する可能性のある情報】

広告識別子（iOS: IDFA / Android: AAID）

IPアドレス

デバイス情報（機種、OS、画面サイズ等）

アプリ使用状況

広告のインタラクションデータ（表示回数、クリック等）

【非パーソナライズド広告について】

本アプリでは、非パーソナライズド広告のみを配信しています。ユーザーの興味関心や過去の行動履歴に基づくパーソナライズド広告は配信されません。

【リワード広告について】

リワード広告の視聴は完全に任意であり、視聴しない場合でも本アプリの基本機能は利用できます。

【広告の非表示】

プレミアムプランに加入することで、すべての広告を非表示にすることができます。

【Google AdMobのプライバシーポリシー】

AdMobのデータ取り扱いに関する詳細は、Googleのプライバシーポリシー（https://policies.google.com/privacy）をご確認ください。

7. 個人情報の管理・保護

本アプリは、お客様の個人情報を適切に管理し、以下の措置により保護いたします。

【データ保存・管理】

当アプリで取得した情報は、Supabase 上の厳重に管理されたサーバーに保存されます。

不正アクセスや紛失を防ぐための多層防御システムを採用しています。

【通信セキュリティ】

通信時には SSL/TLS による暗号化を実施し、すべての API リクエストは HTTPS で送信されます。

【アクセス制御】

Row Level Security (RLS) により、認証されたユーザー本人のみが自分のデータにアクセスできます。

【データ保持期間】

サービス提供に必要な期間、個人情報を保持します。

アカウント削除時または削除請求時には、通常30日以内にデータを削除します。

法令に基づく保存義務がある場合は、その期間に従って保持することがあります。

バックアップデータは、システム復旧に必要な期間（通常最大90日間）保持される場合があります。

9. 個人情報の委託・外部サービスの利用

本アプリは、運営に必要な範囲内で、個人情報の取り扱いを委託することがあります。

【利用する外部サービス】

Supabase（データベース・認証・ストレージ）: 練習記録、ユーザー情報、録音・録画データ、機能利用ログ等を保存。データセンターは AWS（Amazon Web Services）上に構築されています。

Google AdMob（広告配信）: フリープラン向けの非パーソナライズド広告の配信。詳細は第6項を参照。

Apple App Store / Google Play（課金処理）: サブスクリプションの決済処理。クレジットカード情報等は当社では保持しません。

委託先との間で適切な契約を締結し、委託先における個人情報の適切な管理を監督いたします。

10. 個人情報の開示・訂正・利用停止

お客様は、本アプリが保有するお客様の個人情報について、開示、訂正・追加・削除、利用停止・消去、第三者提供の停止を請求することができます。

これらの請求については、お客様ご本人であることを確認の上、合理的な範囲内で対応いたします。請求方法の詳細については、お問い合わせ先までご連絡ください。

11. データのエクスポート

現在、本アプリではアプリ内のデータエクスポート機能を提供しておりません。

アカウント削除前に必要なデータ（練習記録、録音・録画ファイル等）は、ユーザー自身で別途保存していただく必要があります。

データの開示・ポータビリティに関するご請求は、お問い合わせ先（app.gakki@gmail.com）までご連絡ください。合理的な範囲で対応いたします。

将来的にデータエクスポート機能を追加する場合は、本プライバシーポリシーを更新し、アプリ内でお知らせいたします。

12. クッキー・ローカルストレージ等の使用

本アプリ（特に Web 版）は、認証状態の維持、設定の保存、セキュリティの向上、利用状況の分析を目的として、クッキー、localStorage、sessionStorage 等の技術を使用することがあります。

これらにより収集される情報は、サービス提供および改善に必要な範囲に限定されます。

【年齢制限】

本アプリは13歳以上の方を対象としています。13歳未満の方は本アプリを利用できません。

【未成年者（13歳以上18歳未満）の利用について】

18歳未満の未成年者が本アプリを利用する場合は、保護者の同意を得た上で利用してください。

保護者の方は、お子様の本アプリ利用について、適切に監督してください。

【保護者の方へ】

お子様が本アプリを利用する際は、本プライバシーポリシーおよび利用規約の内容を事前にご確認ください。

録音・録画機能および広告表示について、特にご注意ください（第5項・第6項参照）。

14. データ侵害時の対応

万が一、お客様の個人情報が漏洩、滅失、毀損等（以下「データ侵害」といいます）した場合、当社は以下の対応を行います。

事実関係の調査: 速やかにデータ侵害の事実関係、原因、影響範囲を調査いたします。

お客様への通知: 影響を受けるお客様に対して、速やかにメールまたはアプリ内通知にて連絡いたします。

個人情報保護委員会への報告: 法令に基づき、必要に応じて個人情報保護委員会に報告いたします。

再発防止策の実施: データ侵害の原因を分析し、再発防止のための技術的・組織的措置を講じます。
