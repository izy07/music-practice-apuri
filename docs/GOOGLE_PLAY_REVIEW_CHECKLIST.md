### 2. コンテンツレーティング（IARC）⚠️ 重要

Google Play ConsoleでIARC（International Age Rating Coalition）の質問に回答する必要があります。

#### 必須の質問と回答例：

1. **「このアプリは子供向けですか？」**
   - **回答**: **いいえ**（全世代向けの音楽練習アプリ）

2. **「ユーザーが生成したコンテンツの共有」**
   - **回答**: **いいえ**（重要！）
   - **説明**: 
     ```
     このアプリはユーザー自身の演奏録音・録画データを保存しますが、
     他のユーザーや第三者と共有する機能は提供していません。
     すべてのデータはユーザー本人のアカウントにのみ保存され、
     完全にプライベートです。
     ```

3. **「音声・動画の録音・録画機能」**
   - **回答**: **はい**
   - **説明**:
     ```
     ユーザー自身の演奏を録音・録画する機能を提供しています。
     録音・録画データは教育的な目的（練習記録の保存・再生）のみで使用され、
     ユーザー本人のアカウントにのみ保存されます。
     他のユーザーや第三者と共有されることはありません。
     ```

4. **「ソーシャル機能（チャット、コメント、フォロー等）」**
   - **回答**: **いいえ**

5. **「位置情報の収集」**
   - **回答**: **いいえ**

6. **「個人情報の収集」**
   - **回答**: **はい**
   - **説明**:
     ```
     メールアドレス、プロフィール情報、練習記録を収集します。
     詳細はプライバシーポリシーを参照してください。
     ```

7. **「広告の表示」**
   - **回答**: **はい**（AdMobを使用）
   - **説明**:
     ```
     Google AdMobを使用して広告を表示します。
     広告の内容はGoogle AdMobが管理します。
     ```

## 🚨 審査でよくある拒否理由と対策

### 1. プライバシーポリシーのURLが無効
- **対策**: GitHub Pagesなどで公開されていることを確認
- **確認方法**: ブラウザで直接アクセスして表示されることを確認

### 2. データの安全性の説明が不十分
- **対策**: 「ユーザーが生成したコンテンツの共有」→「いいえ」と明確に回答
- **対策**: 録音・録画データが他のユーザーと共有されないことを明記

### 3. サブスクリプション情報が不十分
- **対策**: 料金、更新頻度、キャンセル方法を明確に記載
- **対策**: 利用規約に記載されていることを確認

### 4. 年齢制限の設定が不適切
- **対策**: IARCで「このアプリは子供向けですか？」→「いいえ」と回答
- **対策**: 利用規約に13歳以上の年齢制限を明記

### 5. 権限の説明が不十分
- **対策**: 各権限（マイク、カメラ）の使用目的を明確に説明
