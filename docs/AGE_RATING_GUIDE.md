# 年齢制限設定ガイド（4+対応版）

## 📋 概要

録音機能があるアプリの場合、App StoreとGoogle Play Storeで適切な年齢制限を設定する必要があります。

**このガイドでは、4+（4歳以上）の年齢制限を設定するための具体的な手順と要件を説明します。**

## 🎯 現在のアプリの状況

### 録音機能の使用方法
- ✅ 録音機能あり（マイクアクセス）
- ✅ **録音データ（演奏録音・レッスン録音）をクラウド（Supabase Storage）に保存**
- ✅ **ユーザーアカウントと紐付けて保存**
- ✅ 個人情報（ユーザーID、楽器IDなど）と関連付け
- ✅ **レッスン録音も演奏録音と同じデータ保存方法**（ユーザー自身のアカウントにのみ保存）

### 年齢制限の設定目標

**目標: 4+（4歳以上）**

**4+にするための要件:**

1. **教育的な目的の明確化**
   - 音楽練習・学習アプリとしての目的を明確に説明
   - 録音機能が教育的な目的で使用されることを明記

2. **録音データの使用方法の明確化**
   - 録音データ（演奏録音・レッスン録音）はユーザー自身の練習記録としてのみ使用
   - 録音データ（演奏録音・レッスン録音）は他のユーザーと共有されないことを明記
   - 録音データ（演奏録音・レッスン録音）はアプリの機能（練習記録の保存・再生）のみに使用
   - レッスン録音も演奏録音と同じように、ユーザー自身のアカウントにのみ保存されることを明記

3. **プライバシーポリシーの明確化（子供向け）**
   - 子供のプライバシー保護に関する記述を追加
   - 13歳未満のユーザー向けの説明を追加（COPPA対応）

4. **App Privacy（App Store Connect）での適切な設定**
   - 録音データの収集目的を「教育的な目的」として明記
   - 録音データが「アプリの機能（練習記録の保存・再生）」のみに使用されることを明記
   - 録音データが「他のユーザーと共有されない」ことを明記

5. **Google Play Consoleでの適切な設定**
   - データの安全性で録音データの収集目的を「教育的な目的」として明記
   - 録音データが「アプリの機能（練習記録の保存・再生）」のみに使用されることを明記
   - 録音データが「他のユーザーと共有されない」ことを明記

**重要**: 録音データをクラウドに保存している場合でも、**教育的な目的**を明確に説明し、適切なプライバシーポリシーとApp Privacy設定があれば、4+でも許可される可能性が高いです。

## 🍎 App Store（iOS）- 4+設定手順

### 1. App Store Connectでの年齢制限設定

1. **App Store Connect**にログイン
2. アプリを選択 → **「App情報」**タブ
3. **「年齢制限」**セクションを開く
4. **「4+」**を選択
5. **年齢制限の理由**を入力：
   ```
   このアプリは音楽練習・学習アプリであり、録音機能はユーザー自身の練習記録を保存・再生するための教育的な目的のみで使用されます。
   録音データはユーザー自身のアカウントにのみ保存され、他のユーザーと共有されることはありません。
   録音データはアプリの機能（練習記録の保存・再生）のみに使用され、マーケティングや広告目的では使用されません。
   ```

### 2. app.config.tsでの設定（参考）

`app.config.ts`では以下のようにコメントで記載していますが、**実際の設定はApp Store Connectで行う必要があります**：

```typescript
ios: {
  infoPlist: {
    // 年齢制限: 4+（教育的な目的の音楽練習アプリのため）
    // 録音機能はユーザー自身の練習記録を保存・再生するための教育的な目的のみで使用
    // 実際の設定はApp Store Connectで行う必要がありますが、ここでも明示
  },
}
```

**重要**: `app.config.ts`のコメントは参考情報のみです。実際の年齢制限設定はApp Store Connectで行います。

### 3. App Privacy（App Store Connect）での設定（4+対応版）

**重要**: 4+にするためには、以下の設定が**特に重要**です。

1. **App Store Connect** → **「App Privacy」**タブ
2. **「データ収集の種類」**で以下のデータを追加：

   **✅ 音声データ（録音データ）**
   - **収集目的**: 「アプリの機能」「サービス提供」
   - **詳細説明（必須）**:
     ```
     録音データはユーザー自身の音楽練習記録を保存・再生するための教育的な目的のみで使用されます。
     録音データはユーザー自身のアカウントにのみ保存され、他のユーザーと共有されることはありません。
     録音データはアプリの機能（練習記録の保存・再生）のみに使用され、マーケティングや広告目的では使用されません。
     ```
   - **収集方法**: 「ユーザーが提供」
   - **データの共有**: 「はい」
   - **共有先**: 「クラウドストレージ（Supabase）」
   - **共有目的の詳細説明（必須）**:
     ```
     録音データはユーザー自身のアカウントにのみ保存するために、セキュアなクラウドストレージ（Supabase）に保存されます。
     データは暗号化され、ユーザー本人のみがアクセス可能です。
     他のユーザーや第三者と共有されることはありません。
     ```
   - **トラッキング**: 「いいえ」（録音データはトラッキングに使用されません）

   **✅ ユーザーID**
   - **収集目的**: 「サービス提供」「アプリの機能」
   - **詳細説明**:
     ```
     ユーザーIDはユーザー自身の練習記録や録音データを管理するために使用されます。
     ユーザー自身のアカウントにのみ関連付けられ、他のユーザーと共有されることはありません。
     ```
   - **収集方法**: 「ユーザーが提供」
   - **データの共有**: 「はい」
   - **共有先**: 「クラウドストレージ（Supabase）」
   - **トラッキング**: 「いいえ」

   **✅ デバイスID**
   - **収集目的**: 「サービス提供」
   - **収集方法**: 「自動収集」
   - **データの共有**: 「いいえ」
   - **トラッキング**: 「いいえ」

3. **「子供向けのプライバシー」**セクション（重要）:
   - **「このアプリは子供向けですか？」** → **「いいえ」**（音楽練習アプリは全世代向け）
   - ただし、**「子供のプライバシーを保護しますか？」** → **「はい」**と回答
   - **説明**:
     ```
     このアプリは全世代向けの音楽練習アプリですが、子供のプライバシーを保護するため、
     13歳未満のユーザーのデータ収集については、保護者の同意を取得するプロセスを実装しています。
     録音データを含むすべてのデータは、ユーザー自身のアカウントにのみ保存され、
     他のユーザーや第三者と共有されることはありません。
     ```

## 🤖 Google Play Store（Android）- 4+設定手順

### 1. Google Play Consoleでのコンテンツレーティング設定

1. **Google Play Console**にログイン
2. アプリを選択 → **「アプリのコンテンツ」**タブ
3. **「コンテンツレーティング」**セクションを開く
4. **IARC（International Age Rating Coalition）**で質問に回答：

   **重要**: 4+にするためには、以下の回答が重要です：

   - **マイクの使用**: 「はい」
     - **説明（追加情報）**: 
       ```
       マイクはユーザー自身の音楽練習記録を録音するための教育的な目的のみで使用されます。
       録音データはユーザー自身のアカウントにのみ保存され、他のユーザーと共有されることはありません。
       ```

   - **ユーザーが生成したコンテンツの共有**: 「いいえ」（重要）
     - **説明**: 
       ```
       録音データはユーザー自身のアカウントにのみ保存されます。
       録音データはクラウドストレージに保存されますが、他のユーザーと共有されることはありません。
       録音データはアプリの機能（練習記録の保存・再生）のみに使用されます。
       ```
     - **注意**: 「はい」と回答すると12+以上になる可能性が高いため、**「いいえ」**と回答し、詳細説明で「クラウドストレージへの保存のみで、他のユーザーとの共有はない」ことを明確に説明します。

   - **個人情報の収集**: 「はい」
     - **説明**: 
       ```
       ユーザーIDはユーザー自身の練習記録や録音データを管理するために使用されます。
       ユーザー自身のアカウントにのみ関連付けられ、他のユーザーと共有されることはありません。
       ```

   - **ソーシャル機能**: 「いいえ」
     - 録音データが他のユーザーと共有されないため、「いいえ」と回答

   - **広告**: 「いいえ」または「はい」（広告がない場合は「いいえ」）
   
   - **アプリ内購入**: 「はい」（サブスクリプション機能があるため）

5. **自動的にレーティングが生成されます**：
   - **目標**: 「PEGI 3」（または「ESRB Everyone」）
   - **「ユーザーが生成したコンテンツの共有」を「いいえ」**と回答し、適切な説明を追加することで、4+（PEGI 3 / ESRB Everyone）になる可能性が高くなります。

6. **レーティングが自動生成されない場合**：
   - 「手動でレーティングを申請する」を選択
   - 「教育的な目的の音楽練習アプリ」として申請
   - 録音データがユーザー自身のアカウントにのみ保存され、他のユーザーと共有されないことを明確に説明

### 2. app.config.tsでの設定（参考）

`app.config.ts`では以下のようにコメントで記載していますが、**実際の設定はGoogle Play Consoleで行う必要があります**：

## 🎯 4+設定の重要なポイント

### ✅ 4+にするために必要な条件

1. **教育的な目的の明確化**
   - 音楽練習・学習アプリとしての目的を明確に説明
   - 録音機能が教育的な目的で使用されることを明記

2. **録音データの使用方法の明確化**
   - **最重要**: 録音データが「他のユーザーと共有されない」ことを明記
   - 録音データは「ユーザー自身のアカウントにのみ保存」されることを明記
   - 録音データは「アプリの機能（練習記録の保存・再生）のみに使用」されることを明記
   - 録音データは「マーケティングや広告目的では使用されない」ことを明記

3. **App Privacy / データの安全性での適切な設定**
   - 録音データの収集目的を「教育的な目的」として明記
   - 録音データの共有先を「クラウドストレージ（Supabase）」として明記
   - 録音データが「他のユーザーと共有されない」ことを詳細説明で明記

4. **Google Play Console（IARC）での重要な回答**
   - **「ユーザーが生成したコンテンツの共有」→「いいえ」**と回答（重要）
   - ただし、詳細説明で「クラウドストレージへの保存のみで、他のユーザーとの共有はない」ことを明確に説明

5. **プライバシーポリシーの更新**
   - 録音データの使用方法を明確に記載
   - 13歳未満のユーザー向けの説明を追加（COPPA対応）
   - 保護者の同意取得プロセスについて説明を追加

### ⚠️ 注意事項

- **Google Play Console（IARC）での回答が重要**: 「ユーザーが生成したコンテンツの共有」を「はい」と回答すると、12+以上になる可能性が高いため、**「いいえ」**と回答し、詳細説明で「クラウドストレージへの保存のみで、他のユーザーとの共有はない」ことを明確に説明する必要があります。

- **プライバシーポリシーの更新が必須**: 録音データの使用方法を明確に記載し、子供向けの説明を追加する必要があります。

- **審査時の説明が重要**: App Store/Google Playの審査時に、録音データが「他のユーザーと共有されない」「教育的な目的のみで使用される」ことを明確に説明できるように準備しておく必要があります。

### 📝 結論

**4+にするためには、以下の3つのポイントが特に重要です：**

1. **録音データが「他のユーザーと共有されない」ことを明確に説明**（最重要）
2. **録音データが「教育的な目的のみで使用される」ことを明確に説明**
3. **Google Play Console（IARC）で「ユーザーが生成したコンテンツの共有」→「いいえ」と回答**（重要）

これらの条件を満たせば、録音データをクラウドに保存していても、4+でも許可される可能性が高いです。

**重要**: `app.config.ts`のコメントは参考情報のみです。実際の年齢制限設定は**App Store Connect**と**Google Play Console**で行う必要があります。
